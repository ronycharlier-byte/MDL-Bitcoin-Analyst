# Created Files And Responsibilities

This document records the autonomous brick added under `quant_btc_model`.

## Root

- `README.md`: operating guide, data policy, schema overview, model list.
- `CREATED_FILES.md`: creation manifest.

## Data directories

- `data/raw/`: user-supplied audited CSV inputs.
- `data/processed/`: normalized market and fundamental outputs.
- `data/features/`: technical feature exports.
- `data/backtests/`: reserved for backtest artifacts.
- `data/backtests/latest_backtest.json`: latest generated walk-forward metrics.
- `data/simulations/`: run summaries.
- `data/quant_model.db`: SQLite database initialized by the CLI.

## Knowledge base directories

- `knowledge_base/corpus_raw/`: copied relevant corpus documents.
- `knowledge_base/corpus_chunks/`: chunk JSON files.
- `knowledge_base/metadata/`: corpus copy manifest and pipeline summary.
- `knowledge_base/claims/`: extracted claims as JSONL.

## Model directory

- `models/README.md`: persisted model artifact policy.

## Source files

- `src/config.py`: paths, constants, required directories.
- `src/logging_utils.py`: system logger and missing/mock data helpers.
- `src/database.py`: SQLite schema and insert helpers.
- `src/market_data.py`: market/fundamental loading and MOCK fallback.
- `src/features.py`: technical indicators and returns.
- `src/corpus_pipeline.py`: corpus copy, chunking, claim extraction.
- `src/simulation_utils.py`: shared simulation utilities.
- `src/monte_carlo.py`: base Monte Carlo.
- `src/student_t_model.py`: Student-t model.
- `src/jump_diffusion.py`: jump diffusion model.
- `src/garch_model.py`: GARCH-like model.
- `src/regime_switching.py`: regime switching model.
- `src/liquidation_model.py`: liquidation cascade model.
- `src/correlation_model.py`: macro correlation model.
- `src/ensemble_model.py`: dynamic weighted ensemble.
- `src/risk_metrics.py`: VaR, CVaR, skewness, kurtosis, drawdown, conditional volatility.
- `src/stress_tests.py`: required stress scenarios.
- `src/backtest.py`: hit rate, Brier, calibration, MAE, coverage.
- `src/walk_forward.py`: dynamic recalibration wrapper.
- `src/position_sizing.py`: VaR/CVaR/Kelly/drawdown sizing.
- `src/confidence_score.py`: 0-100 score.
- `src/report.py`: Markdown report generation.
- `src/main.py`: CLI entrypoint.
- `src/__init__.py`: package marker.

## Reports and logs

- `reports/latest_report.md`: generated by a run.
- `reports/dashboard_summary.md`: generated by a run.
- `logs/system.log`: generated/appended by a run.

## Governance export

- `governance_export/gpt_instructions.md`: GPT Custom behavior instructions.
- `governance_export/governance_rules.md`: governance and evidence rules.
- `governance_export/model_card.md`: model card for Knowledge upload.
- `governance_export/data_dictionary.md`: data fields and status definitions.
- `governance_export/claims_registry.md`: compact claim registry and reliability rules.
- `governance_export/source_manifest.md`: compact source manifest without raw database export.
- `governance_export/output_policy.md`: authorized and forbidden output formulations.
- `governance_export/latest_report.md`: Knowledge-ready latest report snapshot.
- `governance_export/dashboard_summary.md`: Knowledge-ready dashboard snapshot.
