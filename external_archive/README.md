# External Live Run Archive

This folder is maintained by GitHub Actions as a free, durable audit layer outside the Render runtime filesystem.

The scheduled archive workflow stores compact summaries only:

- runtime `archive_id`;
- API and Worker versions;
- source policy;
- data/fundamental status;
- compact frame-level distribution and risk metrics;
- no raw simulation arrays or massive data dumps.

Live model outputs remain probabilistic scenario distributions, not deterministic predictions or financial advice.
